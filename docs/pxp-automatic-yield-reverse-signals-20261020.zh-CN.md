# 待避线末尾反向信号检查（2026-10-20）

以列车离开待避线的方向为正向，区分额外放置信号和修改原有“待避出口”信号。

| 放置方式 | 影响 |
|---|---|
| 原出口前后另放一个反向普通 PBS，没有额外限制 | 允许从背面通过；实车测试完成侧线停车、快车出清、慢车离开。原有 PBS 背面代价仍由寻路器处理。 |
| 反向普通 PBS 带禁止通行等寻路限制 | JGRPP 现有规则也会在背面执行限制，可能使侧线不可用。自动待避应尊重这个限制，不能绕过。 |
| 反向单向 PBS 或反向普通区间信号 | 禁止列车沿正常离开方向通过；该股道不能作为可用待避线路。 |
| 将带“待避出口”指令的信号直接转向 | 指令随信号方向转向，不再控制原来的离开方向。 |
| 在原出口同格加上另一面，变成双面信号 | 自动待避角色要求明确的单一方向，因此这个出口标记不参与区域构建；若没有其他有效出口，区域将失效。 |

## 本次确定并修复的问题

自动待避使用的几何轨道跟随器并不检查单向信号方向；之前可能把被反向单向信号封住的线路误判为可用，然后在正线施加待避限制，但真正寻路器无法使用侧线。

现在前向线路证明检查现有 `HasOnewaySignalBlockingTrackdir` 规则；逆向推算股道长度时检查列车的正向合法性，而不是按逆向扫描方向检查，避免把正常出口信号误当成阻挡。没有修改 YAPF、PBS、网络字段或存档格式。

普通 PBS 背面的寻路限制保持原样。实际运行中验证：空白反向普通 PBS 可以正常待避；背面禁止通行和反向单向 PBS 都会让列车保留普通正线通行，不强制进入不可用股道。
