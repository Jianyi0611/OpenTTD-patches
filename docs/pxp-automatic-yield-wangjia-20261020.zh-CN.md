# 王家检测点停车修复与站台强制回退（2026-10-20）

## 王家存档的实际原因

用玩家最新“慢车无法等待.sav”的独立副本复现，未修改原存档。副本和原件 SHA256 一致：`66F5C174B87AD760387594C51A072A2BB561B198108DC4EAEF8C2E49E1608012`。

王家下行源路签 136，容量 5，初始成员为 3 辆；161 号列车认领普通待避线。接近检测位于 (1044,3818)。6 号车停在 (1040,3818)，105 号车在后方。诊断确认旧 BatchClosed 条件返回真，而容量不足条件返回假：只因区内有人认领侧线，就要求未登记列车在接近点等待。

删除这个批次入区封锁条件。接近点保留容量检查和车头实际经过才登记的规则，所有常规信号、占用、预留与寻路限制照常执行。此修改适用于所有区域，不需要重设王家信号。

以上是观测采样刻，并非精确起步瞬间。修复前每 64 刻采样，修复后每 16 刻采样。后车仍需等前车留出实际路径；容量满时仍可在接近点正常停车。

## 空站台的强制回退

需要待避的慢车、普通股道没有可用候选、标记的站台足够长且可安全进出时，通过已有正线寻路限制排除正线选项，让列车使用可用站台。该站台标记所在信号程序的数值惩罚在执行结束后取消，因此惩罚写在标记前后均有效。原有 YAPF/PBS 算法、全局站台成本设置和其他信号的配置均保留。

禁止进入和 PBS 等待指令仍有效。不取消实体占用、他车预留、股道认领或轨道兼容限制。正常停站、路点和连接任务保留；快车、不需要待避或没有登记的列车不会得到该惩罚豁免。普通股道可用时仍优先普通股道。

仍使用原有有限计算预算；路线、站台长度或出清路径无法证明时，不强制入线。偏好判断最多消耗剩余预算的一半且不超过 256 节点，保留原有认领与等待的计算预算。没有新增全图扫描、随机选择、网络命令或存档字段，存档标记保持 v6。联机统一使用相同构建。
