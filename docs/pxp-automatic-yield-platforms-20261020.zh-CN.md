# 自动待避：站台股道（2026-10-20）

## 设置

在寻路限制编辑器中选中“自动待避：待避股道（设在出口）”，将股道类型下拉框由“普通股道”改为“站台股道”。右侧继续选择区域路签。旧入口标记布局也支持该选项，推荐统一在对应出口设置。默认普通股道，不会自动修改已有信号或创建站台。

## 行车与互等保护

- 本站不停的列车需要待避时，优先使用可进入、足够长且没有占用或冲突预留的普通股道；没有合适普通股道时允许站台回退。
- 正常本站停靠、明确路点、前往连接、等待连接及解挂任务保留原有要求，不因偏好而取消任务。已认领股道后，不因其他股道变空而重新选路。
- 站台装卸、满载等待和连接作业不作为必须先通过的快车，也不通过批次关闭阻止其他可用股道接车。
- 有站台标记的区域不会要求正在进行车站作业的列车强制腾位，以免正线等待无法完成的让位；不强制结束满载等待或等待连接，不释放实际有效的路径预留。
- 支持车头超出站台而车身仍在站台作业的长编组。同站编号的未标记股道保留原逻辑；旧布局无法确定站台边界时保守处理。

未更改寻路算法、PBS、轨道兼容与实际占用保护。这些措施减少待避自身造成的互等，不能解决线路没有出路或所有站台长期满载等待等布局问题。

## 性能与存档

单次判断共用 1024 探测节点，单次路线证明最多 256 节点。普通股道偏好最多使用剩余预算的一半且不超过 256 节点，保留原有等待与认领计算预算。未标记站台的区域保留原逻辑。

`pxp_automatic_yield` 存档标记升级为 v6，沿用现有指令第二字的标记位，无新增存储字段。可读取 v1～v5；新版保存后需新版程序读取。多人联机所有参与者需使用相同版本。编辑使用现有同步命令，支持程序复制和蓝图底层程序复制。
