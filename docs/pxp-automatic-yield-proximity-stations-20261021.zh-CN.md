# 同速近距离让行、短暂停站与河湾口检查

## 规则调整

- 同速客货车仅在同一正线的客车紧随货车时触发新待避：按到同一正线标记的路线长度比较，扣除货车长度后，间隔最多 16 格。未知方向或距离不能引入同速待避。
- 出口等待使用到共同车尾出清点的前向路线判断近距离，保护已靠近或正在并行越过的客车。速度确实更高的列车继续使用原速度差规则，不受此 16 格限制。
- 普通短暂停站不立即取消优先权；短暂卸客时，仍有客运容量的正在装卸列车保留客车识别，避免卸空的一瞬间改变优先级。
- 满载、按货物类型装载、等待连接等可能长时间停留的任务不无限扣车。普通停站的保护窗口为 256 游戏刻；计划等待超过此值或本次停站已达到此值时恢复释放处理。不是现实时间计时。
- 腾位例外也检查短暂停站保护，避免绕过出口等待；正在装卸、解挂和等待连接的列车仍不能被强制腾位。
