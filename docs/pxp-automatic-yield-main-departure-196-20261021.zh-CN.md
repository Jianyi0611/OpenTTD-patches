# 提前放行列车优先走正线（196 号，2026-10-21）

原始存档中，196 号已被容量不足规则选为提前放行车，但是先前已认领并预留普通待避线，仍绕侧线通行。此次让这类列车在尚未越过分岔时优先使用正线。

## 适用条件

必须是当前腾位方案确定放行的车，并且还持有待避股道认领；正线及其到出清点的通路必须可用；命令必须是普通回库或车站命令，不得处于车站作业。若需要所认领站台，或无法证明当前车站命令不需要该侧线，保留原路线。路点、前往连接、等待连接和解挂命令不使用此优化。

正线标记对符合条件的车不再要求重新进入待避线；侧线路径使用轻量费用偏好，保留仍需走侧线的路径选择。已有侧线预留在正常模拟循环、分岔之前通过现有 PBS 函数重算。已经进入侧线、正线受阻或没有被选为安全放行的车继续使用原逻辑。股道认领保留至原有车尾出清事件，防止后车提前占用仍受保护的路径。

没有改写寻路算法或增加存档字段。复用现有模拟刻复核及探测预算，已在侧线内的车先做简短的正线可达性检查，避免反复计算完整腾位方案。
