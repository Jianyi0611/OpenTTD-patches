# 待避停车与侧线出线优化（2026-10-20）

## 调整后的规则

普通待避仍然等同一路签中的有效快车车尾出清。为了给更慢的来车腾位而提前出线，现在必须同时满足以下条件：

1. 来车后方确实存在达到速度差阈值的快车，且来车尚未认领股道。
2. 来车没有其他已证明可用的空闲侧线。能直接使用空线时，不要求已停列车让位。
3. 被要求让位的车比这辆来车更快，且自己的出清线路可用。
4. 来车能进入腾出的这条具体侧线，长度足够，并且能按自身轨道兼容性继续出清；已过岔口、线路被其他车辆堵住、寻路限制禁止、车长不合适等情况，不要求腾位。
5. 更快的列车若已在来车前方或正在正线通过，先让它完成通过，不能为了后方的另一辆车而抢先插入快车前方。

多个来车需要腾位时，按最高速度从低到高、到正线控制点的路线长度、车辆编号依次选择。选定来车后，优先选择能完成让位的较快侧线列车。只有被选中的来车在正线等待腾位，其余车辆保留普通通行行为。

上述预测没有增加检测距离、超时强制开出或强制抢路。车尾出清、手动取消路签、总开关和普通寻路限制的规则不变。

## 实现与安全边界

- 让位方案包含“哪辆车离开、给哪辆车腾位”，替代原先只返回出线车辆的判断。
- 预测来车能否使用某条侧线时，只在只读检查中暂不计算拟离开车辆的占用和自身可识别预留；其他车辆、占用、信号方向、寻路限制和轨道兼容性仍检查。
- 预测不会实际释放任何预留、路签或隐藏股道认领。真正出线仍由现有 PBS 预留和信号控制；真正进线仍要求股道已可用。
- 计算仍受单路线 256 节点、单次动作 1024 节点、最多 16 辆参与车辆和 16 条侧线的原有上限约束，没有增加全图扫描或持久化调度状态。
- 使用整数速度、固定车辆编号和游戏状态排序，没有新随机调用、本机计时、网络协议或存档字段。未修改 YAPF/PBS 寻路算法。
