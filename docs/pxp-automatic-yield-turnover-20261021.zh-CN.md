# 自动待避：合流、腾位和检测时机复查（2026-10-21）

## 本轮规则

- 同一路签的不同来线，只有证明沿各自正线最终汇入同一车尾清除点，才比较合流优先级；快车已在前方时，不让后面的办客慢车抢先出站。串联的正线标记不作为两条独立来线。
- 空位优先留给速度最低的可入线慢车；同速同客货等级时，再比较与后方快车的沿线距离。没有改变 YAPF/PBS 寻路机制。
- 普通待避换位只考虑出路可达、来车可使用腾出的股道、长度足够，且不慢于来车的候选。办理明确目标车站的站台准入腾位允许速度较低的占用者安全离开，详见同目录 pxp-automatic-yield-stopping-express-20261021.zh-CN.md。正在装卸或执行连接作业的列车不能被强制放走。
- 同速候选先选标记为站台的股道，再优先该速度组的客车；同时支持旧入口标记和仅出口标记。没有后方停站客车需要站台时，速度组之间保留原有客车优先、同类选最快的规则。
- 后方有本次命令确实要在该站停靠、且能到达该站台股道的客车时，优先腾出所需站台，先选站台上的最高检测速度，速度相同再选客车。客车包括有载客能力的空车；普通沿线待避的同速载客优先仍使用既有实际载客条件。
- 上述站台腾位规则不越过既有“快车正在通过”“较高优先级短暂停站”保护。办客慢车在快车后面时，先等快车通过。不能绕过信号、铁路兼容性、列车长度、装卸及连接命令。
- 为避免比较规则在三个候选之间互相矛盾，先确定每个速度组的代表，再选择最终腾位者；最终相同条件按车辆 ID 决定，不使用随机数、本机时间或本地公司。
- 同速来车距离超过 32 个沿线轨道格时允许安全腾位；近距离通常保留待避。仅当侧线车、来车和后方优先车构成已停止的阻塞队列、并且出路安全时，允许同速腾位解围，不驱逐比来车更慢的候选。
- 接近检测新增领取时机：成功预留路径、车头通过、车尾通过。后两者不会在路径试探时提前领签。仍由车尾清除点退出，临时领取仍按既有事务回滚。旧存档默认预留路径模式。

## 安全性与性能边界

排序只改变已通过检查的候选顺序，不直接开信号或删除其他列车预留。合流证明与停止队列检查都复用每次评估总计 1024 节点的预算；证明不足时不新增合流/近距腾位许可。不引入每游戏刻扫描全地图的新任务，不改写模拟多线程结构。

无可用出路、信号反向封锁、路签容量不足、列车长于所有股道或人为停止等情况，不能靠排序保证自动解开。因此本轮解决已复现死锁并覆盖相应回归，不宣称任意地图布局下绝不会死锁，也不宣称实现全局最优调度。
