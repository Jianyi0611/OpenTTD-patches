# 荒山站自动待避复现与相关代码检查（2026-10-20）

## 复现与根因

使用根目录 `慢车无法等待.sav`（10,035,912 字节，2026-10-20 00:48:35 版本），没有覆盖或保存原文件。总开关已开启，上、下行源路签容量均为 10；问题不是没有开启设置。

1. **站台被当成不可用股道**。`InferredSidingLength` 原来只接受普通铁路地块，遇到站台立即返回无法证明长度；空闲路径检查也直接拒绝跟随器跳过站台的结果。荒山上行三条出口反查分别在 `(1329,3792)`、`(1330,3791)`、`(1331,3791)` 遇到站台，下行两条同样遇到站台。五条股道长度全部无法识别，因此即使发现快车，慢车仍按普通线路通过。
2. **普通桥梁断言崩溃**。空闲路径证明无条件调用 `GetExistingTraceRestrictProgram`，其桥梁分支要求桥梁具有模拟信号；诊断实际触发 `tunnelbridge_map.h:569` 断言，地块 `(1449,3804)`。现在先验证地块支持信号限制，再读取限制程序。

修复后，上行长度分别为 18、17、18 格，下行为 19、20 格。站台跨越时逐格检查车辆及预留，并计入原有计算预算；桥隧跨越仍不能凭未检查的中间区间证明空闲。没有修改 YAPF/PBS 寻路与预留算法，也没有修改存档格式。
